# Brawlhalla Combo Macro

Um programa em Python para executar true combos no Brawlhalla com timing preciso.

## Combos Implementados

### Sword
- DLight -> SAir (True Combo)
- DLight -> Recovery (True Combo)

### Axe
- DLight -> NAir (4-5 dodge window)
- SLight -> NAir (4-5 dodge window)

## Como Usar

1. Instale as dependências:
```bash
pip install -r requirements.txt
```

2. Execute o programa:
```bash
python main.py
```

3. Selecione a arma e o combo
4. Pressione T para executar o combo

## Configuração de Teclas
- C: Ataque leve
- X: Ataque pesado
- WASD: Movimento
- SPACE: Pulo
